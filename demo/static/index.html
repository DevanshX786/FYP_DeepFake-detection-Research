CDTC-Net Architecture
Detailed architecture of the proposed deepfake detection network.
Architecture diagram
CDTC-Net combines spatial RGB features and frequency-domain features through cross-domain fusion. Explicit signed and absolute temporal differences are then constructed from consecutive fused frame representations. These representations are processed together with a learnable [CLS] token by a two-layer Transformer, whose contextualized [CLS] representation is used for final classification.

Research Note
CDTC-Net is a research prototype rather than a definitive forensic decision system. Performance is affected by class imbalance, manipulation distribution shift, temporal sampling, and false-positive/false-negative trade-offs. The demonstration intentionally includes unsuccessful and near-threshold predictions.
